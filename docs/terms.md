## What this is

Memory Steward is an experimental prototype built for the "Build, Ship, Shape: Amazon
Developer Hackathon". It lets a voice assistant keep long-term memory in a Markdown file
that you own. The web simulator ("Simulated Alexa+") is a demonstration, not an Amazon
product.

## Using it

- Use it only with memory you are allowed to store. You are responsible for what you
  ask it to remember and for the contents of your memory file.
- Don't store passwords, financial account numbers, health information or other
  sensitive data, and don't store information about other people without their
  permission.
- Don't try to access memory that isn't yours, overload the service, or bypass its
  sign-in.
